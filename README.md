# 📱 «Шаблон выгрузки» — версия для iPhone

Автономное веб-приложение (PWA): тот же функционал, что у настольной программы,
но работает прямо на iPhone — без App Store, бесплатно и без ограничений по сроку.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Всё приложение: интерфейс + логика (порт `main.go`/`import_excel.go`/`checks.go` на JavaScript) |
| `data.js` | Встроенные данные (56 сотрудников, справочник стажа, баллы, статистика) |
| `manifest.webmanifest` | Описание приложения (иконка, имя, полноэкранный режим) |
| `sw.js` | Service worker — офлайн-работа после первого открытия |
| `icon-180/192/512.png` | Иконки приложения |

## Установка на iPhone (2 телефона)

### Шаг 1. Разместить файлы в интернете (один раз, бесплатно)

Нужен любой HTTPS-хостинг — iOS ставит PWA только с HTTPS. Проще всего GitHub Pages:

1. Создайте аккаунт на github.com (если нет).
2. Создайте репозиторий, например `shablon`.
3. Загрузите в него **все файлы из этой папки** (Add file → Upload files).
4. Settings → Pages → Source: `main` → Save.
5. Через 1–2 минуты сайт будет доступен по адресу
   `https://ВАШ_НИК.github.io/shablon/`

Альтернатива без git: Netlify Drop (app.netlify.com/drop) — перетащить папку, нужен аккаунт.

### Шаг 2. Установить на каждый iPhone

На каждом телефоне в Safari:

1. Открыть адрес сайта из шага 1.
2. Кнопка «Поделиться» (квадрат со стрелкой) → **«На экран „Домой“»**.
3. Нажать «Добавить».

Появится иконка 📋 — приложение запускается с иконки, в полный экран, **работает без интернета**.

## Данные и хранение

- Все правки автоматически сохраняются **в память самого телефона** (localStorage).
- При первом открытии загружаются встроенные данные из `data.js`.
- ⚠️ **Резервные копии:** раз в 1–2 недели нажимайте «⚙ Настройка → 📤 Экспорт JSON»
  и сохраняйте файл в «Файлы»/почту. Если очистить данные сайта в Safari —
  правки пропадут, и восстановить их можно будет только из экспорта.
- Перенос между iPhone и компьютером: экспорт JSON на одном → импорт JSON на другом.

## Возможности (как в настольной версии)

- ⚡ Авто: Excel → дубли → сведение → шаблон
- 📥 Загрузка из Excel (листы «Баллы», «Статистика», «Стаж», лист-форма «шаблон»)
- Вкладки: Шаблон, Баллы, Статистика, Решение, Стаж, Проверка
- Сведение с нечётким сопоставлением ФИО (ПРОФСЕРВИС, АС_-префиксы, опечатки, усечённые имена)
- Авто-категории и раскраска строк (аутсорс/новенькие/отстающие/подработка)
- 🧪 Проверка дублей с разбором прямо в приложении
- 💾 Отчёт в Excel — файл .xlsx через системное меню «Поделиться»
  *(упрощённый: без цветной заливки — её накладывает только Excel на компьютере)*
- Календарь, кнопка «⏮ Вчера», маска даты ДД.ММ.ГГГГ
- Экспорт/импорт JSON, экспорт CSV

## Локальная проверка на компьютере

```bash
cd iphone
python3 -m http.server 8901
# открыть http://localhost:8901
```

Просто двойной клик по index.html **не даст** поставить приложение на iPhone
(нужен HTTPS-хостинг), но для правок интерфейса на компьютере — пригодится.

## Отличия от настольной версии

- Нет лог-файла app.log (не нужен на телефоне).
- Отчёт .xlsx без цветной заливки и рамок (ограничение бесплатной SheetJS).
- Нет нативного диалога «Открыть в Excel» — файл сохраняется через «Поделиться».
- Приложение должно один раз открыть страницу при интернете, чтобы закэшировать
  библиотеку чтения Excel; после этого полностью офлайн.
