Данные

Все изменения автоматически сохраняются в память iPhone (localStorage) — интернет не нужен.
Важно: раз в неделю-две делайте «📤 Экспорт JSON» — это резервная копия на случай очистки Safari.

О приложении

Автономная версия настольной программы «Шаблон выгрузки» для iPhone/iPad.
Работает офлайн; загрузка Excel — через SheetJS (загружается из сети один раз, потом из кэша).
Отчёт «💾 Отчёт в Excel» создаёт файл .xlsx и открывает меню «Поделиться» — файл можно сохранить в «Файлы» или отправить в почту/мессенджер.
